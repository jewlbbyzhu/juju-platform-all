## 解决方案

### 方案1: 检查服务器上的服务状态
```bash
# 在服务器上执行
sudo systemctl status mysql
sudo systemctl status redis
sudo netstat -tlnp | grep -E "3306|6379"
```

### 方案2: 修改数据库监听配置
如果数据库只在本地监听，需要修改为监听所有接口：
```bash
# my.cnf
bind-address = 0.0.0.0

# redis.conf
bind 0.0.0.0
```

### 方案3: 配置防火墙
```bash
# 开放端口（谨慎操作）
sudo ufw allow 3306/tcp
sudo ufw allow 6379/tcp
```

### 方案4: 使用本地数据库（临时方案）
修改.env.production使用本地数据库：
```
DB_HOST=localhost
REDIS_HOST=localhost
```
