### Bug #1: BACK键导航Bug（🔴 HIGH）

**描述**: 在登录页按BACK键，APP直接退出到Android桌面，而非返回上一页。

**证据**: 
- 截图1: 登录页正常显示
- 截图2: 按BACK后显示Android桌面（非APP页面）

**根因**: APK构建于2026-05-02 04:05，不包含App.tsx中的BackHandler修复代码。

**修复状态**: 代码已修复，但APK未重新构建。

### Bug #2: 用户协议链接无响应（🟡 MEDIUM）

**描述**: 点击登录页底部《用户协议》文字无任何反应，未打开协议页面。

**证据**: 
- 坐标点击(540, 1900)后无页面跳转
- 多次尝试均无效

**根因**: 协议文字可能使用TextView而非TouchableOpacity，缺少onPress事件处理。

**修复状态**: 未修复。

### Bug #3: 后端不可达（🟡 MEDIUM）

**描述**: 模拟器无法连接后端API（10.0.2.2:18789），导致所有登录后流程无法测试。

**根因**: 后端服务可能未绑定0.0.0.0，仅监听localhost。

**影响**: 首页、分类、详情页、个人中心等7个测试用例被迫跳过。

## 已知限制

1. **ADB性能严重降级**: 大多数ADB命令超时，仅screencap和少量shell命令可用
2. **Appium会话无法创建**: 会话创建API超时（60秒），无法使用Appium进行自动化测试
3. **APK版本过旧**: 不包含2026-05-02之后的任何修复
4. **后端连接问题**: 模拟器与宿主机后端网络不通

## 建议

1. **立即重新构建APK**: 清理build目录和assets bundle后重新打包，确保包含最新修复
2. **修复用户协议链接**: 将Text改为TouchableOpacity并添加onPress handler
3. **检查后端绑定地址**: 确保后端服务绑定0.0.0.0而非localhost
4. **重启ADB/模拟器**: 解决ADB连接性能问题
5. **使用Appium send_keys**: 替代adb shell input text进行登录测试
