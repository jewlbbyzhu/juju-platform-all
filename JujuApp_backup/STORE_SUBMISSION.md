## 应用描述

### 简短描述（80字以内）
发现精彩派对，结识志同道合的朋友。聚聚帮你找到身边的聚会、活动，一键报名参加。

### 完整描述
```
聚聚 - 发现身边的精彩派对

聚聚是一款专注于派对、聚会、活动社交的平台。
无论你是想参加派对，还是组织活动，聚聚都能帮你找到志同道合的朋友。

主要功能:
• 发现附近的热门派对和活动
• 一键报名参加感兴趣的活动
• 创建自己的派对，邀请朋友参加
• 实时聊天，认识新朋友
• VIP会员特权，享受专属服务
• 钱包支付，安全便捷

特色亮点:
✨ 精选活动 - 每日精选优质派对
🎉 一键报名 - 快速参加活动
💬 即时沟通 - 与活动参与者实时聊天
👑 VIP特权 - 专属标识和特权服务
💰 安全支付 - 支持微信、支付宝、钱包支付

适用场景:
• 周末聚会派对
• 户外活动探险
• 兴趣小组活动
• 商业社交活动
• 生日派对聚会

快来聚聚，开启你的精彩社交生活！
```

## 应用截图要求

### 必备截图（5-10张）
1. **首页/发现页** - 展示活动列表
2. **活动详情页** - 展示活动信息、报名方式
3. **个人中心** - 展示用户资料、VIP状态
4. **我的订单** - 展示订单列表
5. **聊天界面** - 展示社交功能

### 截图规格
- 尺寸: 1080x1920px
- 格式: PNG/JPG
- 大小: 每张 < 2MB
