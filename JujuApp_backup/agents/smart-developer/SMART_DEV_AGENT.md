# 智能开发Agent - 基于Kimi API优化版

## 设计思路

不用额外配置Claude Code/Codex，直接用Kimi API + 精心设计的Prompt来实现智能开发。

## Agent能力

### 1. 代码分析
- 分析页面重构进度
- 识别需要优化的代码
- 生成重构方案

### 2. 代码生成
- 生成符合2026设计系统的代码
- 批量生成相似页面
- 自动修复常见问题

### 3. 质量检查
- 检查Theme系统使用
- 检测深色主题残留
- 验证代码规范

## 执行流程

```
1. 分析阶段
   ↓ 读取当前代码状态
   ↓ Kimi分析需要重构的页面
   ↓ 生成具体重构计划

2. 生成阶段
   ↓ Kimi生成新代码
   ↓ 保存到临时文件
   ↓ 对比验证

3. 应用阶段
   ↓ 替换原文件
   ↓ Git提交
   ↓ 生成报告
```

## Prompt模板

### 分析Prompt
```
分析以下React Native页面代码：
- 检查是否使用了2026设计系统
- 检查是否有深色主题残留
- 给出重构建议
- 输出具体的代码修改方案
```

### 生成Prompt
```
重构以下页面使用2026设计系统：
要求：
1. 使用Theme颜色系统
2. 添加玻璃拟态效果
3. 统一字体和间距
4. 保持原有功能

输出完整的tsx代码：
```

## 优势

1. **零额外配置** - 使用现有Kimi API
2. **成本低** - 无需额外API费用
3. **可控性强** - 每步都可审查
4. **效果好** - Kimi代码能力强
