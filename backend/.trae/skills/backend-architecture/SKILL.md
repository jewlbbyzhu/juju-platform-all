# 后端架构 Skill

## 使用范围
- 后端系统整体架构咨询
- 技术栈相关问题
- 项目目录结构说明
- 系统分层设计解释

## 内容边界
本Skill仅包含架构层面的信息，不涉及：
- 具体API端点详情（见 api-reference Skill）
- 数据库表结构详情（见 data-models Skill）
- 认证实现细节（见 auth-system Skill）

## 架构概述

聚聚平台后端采用 **Node.js + Express** 构建，遵循经典的三层架构模式。

### 技术栈

| 类别 | 技术 | 版本 |
|------|------|------|
| 运行时 | Node.js | >=16.0.0 |
| Web框架 | Express | 4.18.2 |
| 数据库 | MySQL | 8.0+ |
| ORM | Sequelize | 6.35.0 |
| 缓存 | Redis | 4.6.12 |
| 认证 | JWT | 9.0.2 |
| 验证 | Joi | 17.11.0 |
| 日志 | Winston | 3.11.0 |

### 分层架构

```
┌─────────────────────────────────────┐
│           路由层 (Routes)            │
│     API端点定义、请求路由、版本控制     │
├─────────────────────────────────────┤
│         控制器层 (Controllers)        │
│   请求处理、参数校验、调用Service      │
├─────────────────────────────────────┤
│         业务层 (Services)            │
│   业务逻辑处理、事务管理、协调Model     │
├─────────────────────────────────────┤
│          数据层 (Models)              │
│   Sequelize ORM模型、数据库操作        │
└─────────────────────────────────────┘
```

### 目录结构

```
backend/
├── src/
│   ├── config/           # 配置文件
│   ├── constants/        # 常量定义
│   ├── controllers/      # 控制器层
│   ├── middleware/       # 中间件
│   ├── models/           # 数据模型
│   ├── routes/           # 路由层 (v1, v2)
│   ├── schemas/          # 验证Schema
│   ├── services/         # 业务逻辑层
│   ├── utils/            # 工具函数
│   ├── validators/       # 请求验证器
│   └── server.js         # 应用入口
├── tests/                # 测试目录
├── migrations/           # 数据库迁移
└── logs/                 # 日志目录
```

### 设计原则

- **分层清晰**: 路由层 → 控制器层 → 业务层 → 数据层
- **多客户端支持**: 适配器模式支持四种客户端类型
- **安全性**: JWT认证、Token黑名单、请求限流、数据脱敏
- **可扩展性**: 模块化设计，易于添加新功能
