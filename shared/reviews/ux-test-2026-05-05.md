## Appium会话问题诊断与修复

### 问题
```
SessionNotCreatedError: A new session could not be created. 
Details: Session capabilities format must comply to the W3C standard.
```

### 根因分析
1. **Appium v3.x 要求 W3C 格式**：`desiredCapabilities` 格式已被废弃
2. **ANDROID_HOME 未设置**：Appium 进程无法找到 Android SDK

### 解决方案
```bash
# 1. 设置环境变量后启动 Appium
ANDROID_HOME=/Users/mac/Library/Android/sdk \
ANDROID_SDK_ROOT=/Users/mac/Library/Android/sdk \
appium --address 127.0.0.1 --port 4723

# 2. 使用 W3C capabilities 格式创建会话
POST /session
{
  "capabilities": {
    "alwaysMatch": {
      "platformName": "Android",
      "appium:automationName": "UiAutomator2",
      "appium:deviceName": "emulator-5554",
      "appium:app": "/path/to/app-release.apk"
    },
    "firstMatch": [{}]
  }
}
```
