### 2. BACK键导航 ❌ FAIL

**问题描述**: 从登录页按BACK键直接退出APP，回到Android桌面。

**验证过程**:
1. APP当前窗口: `com.jujuapp/com.jujuapp.MainActivity`
2. 按BACK键后窗口: `com.google.android.apps.nexuslauncher/NexusLauncherActivity`
3. APP进程仍在运行，但Activity被销毁

**根因分析**:
- `App.tsx` 代码已添加 `BackHandler` 拦截（2026-05-03修复）
- 但APK最后构建时间为 **2026-05-02 04:05**
- JS bundle (`index.android.bundle`) 中不包含修复代码
- **必须重新构建APK**才能包含此修复

**修复状态**: ⚠️ 代码已修复，APK未重建

### 3. 登录流程 ⏭️ SKIP

**问题描述**: 无法完成登录，后端API不可达。

**测试过程**:
1. ✅ 成功输入手机号 `13800138000`
2. ✅ 成功输入验证码 `123456`
3. ✅ 点击"获取验证码"按钮
4. ✅ 点击"立即登录"按钮
5. ❌ 显示"网络错误"弹窗

**根因分析**:
- 模拟器访问 `10.0.2.2:18789` 失败
- 宿主机 `localhost:18789` 正常
- 后端服务可能未绑定 `0.0.0.0`
- 影响：所有需要登录的测试（首页、TabBar、个人中心等）无法执行

**验证命令**:
```bash
adb shell "curl -s http://10.0.2.2:18789/api/v1/health"
# 结果: 无响应（超时）
```

## 建议

1. **立即重新构建APK**: BACK键修复已合并到代码，但APK未更新。需执行完整构建流程：
   - 清理 `android/app/build/outputs/apk`
   - 清理 `android/app/src/main/assets/index.android.bundle`
   - 执行 `npx react-native bundle`
   - 执行 `./gradlew assembleRelease`

2. **修复用户协议链接**: 将 `Text` 组件改为 `TouchableOpacity` 或添加 `onPress` handler

3. **排查后端连接问题**: 确认后端服务绑定 `0.0.0.0:18789` 而非 `localhost:18789`

4. **adb input text陷阱**: 本次测试使用 `adb shell input text` 输入手机号/验证码，**不触发React Native `onChangeText` 事件**。虽然原生层显示输入内容，但JS层状态可能未更新。登录测试中后端不可达是主要 blocker，此陷阱未造成实际影响，但后续UX测试需注意。
