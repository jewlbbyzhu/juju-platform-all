## 修复详情

### 1. MyOrdersScreen.tsx - useFocusEffect Hook修复

**问题**: 
```tsx
useFocusEffect(
  useCallback(() => {
    fetchOrders(1, true);  // 直接调用，但fetchOrders未在依赖中
    // eslint-disable-next-line react-hooks/exhaustive-deps (重复3次)
  }, [activeTab]),
);
```

**修复**:
```tsx
useFocusEffect(
  useCallback(() => {
    fetchOrdersRef.current?.(1, true);  // 使用ref引用最新函数
  }, [activeTab]),
);
```

**理由**: `fetchOrdersRef.current`始终指向最新`fetchOrders`函数，避免闭包陷阱。

### 2. PartyDetailScreen.tsx - 错误处理改进
