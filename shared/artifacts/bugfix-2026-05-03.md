### Bug 1: 明文密码迁移生产环境风险
**文件**: `backend/src/routes/v1/auth.js:107-130`
**修复前**: 明文密码在生产环境也可登录并自动升级
**修复后**: 
```javascript
if (user.password.startsWith('$2')) {
  isValidPassword = await bcrypt.compare(password, user.password);
} else if (process.env.NODE_ENV !== 'production') {
  // 明文密码（旧数据迁移，仅开发/测试环境允许）
  isValidPassword = (password === user.password);
  // ...
} else {
  // 生产环境：明文密码已废弃，拒绝登录
  return res.status(401).json({ success: false, message: '密码格式错误，请重置密码' });
}
```

### Bug 2: 微信登录生产环境placeholder
**文件**: `backend/src/routes/v1/auth.js:163-176`

**修复后**: 生产环境微信登录返回501错误，要求真实微信API集成

```javascript
if (!process.env.WECHAT_APPID || !process.env.WECHAT_SECRET) {

return res.status(501).json({ success: false, message: '微信登录功能正在维护中' });
```
