## 修复详情

### 🔴 P0 - encryption.js 盐值保存
**问题**: `encryptString`使用随机盐派生密钥但盐值未保存，导致`decryptString`无法解密
**修复**: 加密结果改为 `salt:encrypted` 格式，解密时提取盐值重新派生密钥

### 🔴 P0 - server.js CORS截断
**问题**: `credentials: process.env.CORS_CREDENTIALS=*** 'true'` 语法被截断
**修复**: 改为 `credentials: process.env.CORS_CREDENTIALS === 'true'`

### 🔴 P0 - 注册强制验证码
**问题**: `if (code)` 使验证码可选，允许无验证码注册
**修复**: `if (!code)` 返回400错误，强制要求验证码

### 🔴 P0 - reset-password无密码用户
**问题**: `!user.password` 时 `passwordValid` 保持false，导致无法重置
**修复**: 无密码用户允许通过验证码直接重置密码

### 🔴 P0 - crypto.randomInt
**问题**: `Math.random()` 非加密安全随机数
**修复**: 使用 `crypto.randomInt(100000, 999999)`

### 🟡 P1 - 验证码路由统一
**问题**: `/verify-code`, `/send-code`, `/verification-code` 三个路由代码完全重复
**修复**: 提取为 `sendVerificationCode()` 统一函数

### 🟡 P1 - logout加入黑名单
**问题**: logout未使Token失效
**修复**: 解析Token并调用 `TokenBlacklist.addToBlacklist()`

### 🟡 P1 - authLimiter收紧
**问题**: 15分钟1000次过于宽松
**修复**: 15分钟20次

### 🟡 P1 - 测试Token空保护
**问题**: `TEST_TOKENS` 为空时 `testTokens` 为空数组，但逻辑仍可能绕过
**修复**: 空数组时直接返回false

### 🟡 P1 - DEBUG日志清理
**问题**: `partyController.js` 有 `console.log` 调试残留
**修复**: 注释标记为已移除

### 🟢 P2 - RN config NODE_ENV
**问题**: `process.env.NODE_ENV` 在RN打包后不存在
**修复**: 仅依赖 `__DEV__` 判断，`isRelease = !isDev`

### 🟢 P2 - orderController权限
**问题**: `getOrderList` 中 `user_id` 无权限校验
**修复**: 管理员查看全部，普通用户只能查看自己的订单
