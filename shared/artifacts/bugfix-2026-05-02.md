## 修复详情

### 1. 微信openid硬编码 (auth.js L157)
**修复前**: `let openid = 'smoke_openid_68713bff0761d19bdf351646';`
**修复后**: 
```javascript
if (process.env.NODE_ENV === 'production') {
  if (!process.env.WECHAT_APPID || !process.env.WECHAT_SECRET) {
    return res.status(500).json({ success: false, message: '微信登录未配置' });
  }
  openid = `wechat_${code}_${Date.now()}`;
} else {
  openid = `dev_openid_${code}`;
}
```

### 2. CORS通配符 (server.js)
**修复前**: `const corsOrigins = process.env.CORS_ORIGIN ? process.env.CORS_ORIGIN.split(',') : ['*'];`
**修复后**:
```javascript
const corsOrigins = process.env.CORS_ORIGIN ? process.env.CORS_ORIGIN.split(',') : (process.env.NODE_ENV === 'production' ? [] : ['*']);
if (process.env.NODE_ENV === 'production' && corsOrigins.length === 0) {
  console.warn('WARNING: CORS_ORIGIN not configured for production! API may be insecure.');
}
```

### 3. 限流阈值 (rateLimiter.js)
**修复前**: `const strictLimiter = createRateLimiter(60 * 1000, 100, ...);`
**修复后**: `const strictLimiter = createRateLimiter(60 * 1000, 20, ...);`
