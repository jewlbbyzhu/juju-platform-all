## 快速开始

### 环境要求
- Node.js >= 16.0.0
- npm >= 8.0.0

### 安装依赖
```bash
cd admin-web
npm install
```

### 开发环境运行
```bash
npm run dev
```
访问: http://localhost:5173

### 生产环境构建
```bash
npm run build
```

### 运行测试
```bash
npm test
```

## 系统登录

### 登录步骤
1. 打开浏览器访问管理后台地址
2. 输入管理员用户名和密码
3. 点击"登录"按钮
4. 登录成功后自动跳转到仪表盘

### 默认账号（开发环境）
- 超级管理员: `admin` / `admin123`
- 运营管理员: `operation` / `operation123`
- 财务管理员: `finance` / `finance123`
- 客服管理员: `cs` / `cs123`

### 忘记密码
请联系超级管理员重置密码

## 功能模块

### 1. 仪表盘
查看平台核心数据统计和趋势分析

**功能特性:**
- 用户总数、聚会总数、订单总数、收入总额
- 数据增长率对比（与昨日对比）
- 趋势图表（最近30天）
- 快捷操作入口

**使用方法:**
1. 登录后默认进入仪表盘
2. 查看各项统计数据
3. 点击数据卡片可跳转到详细页面
4. 数据每5分钟自动刷新

### 2. 用户管理
管理平台所有用户信息

**功能特性:**
- 用户列表查看（分页、搜索、筛选）
- 用户详情查看
- 用户状态管理（封禁/解封）
- 用户数据导出

**使用方法:**
1. 点击左侧菜单"用户管理"
2. 使用搜索框按昵称、手机号、ID搜索用户
3. 使用筛选器按注册时间、VIP状态、用户状态筛选
4. 点击用户行查看详情
5. 在详情页可以查看用户统计数据和行为记录
6. 点击"封禁"或"解封"按钮管理用户状态

### 3. 聚会审核
审核用户创建的聚会活动

**功能特性:**
- 待审核聚会列表
- 聚会详细信息查看
- 审核操作（通过/拒绝）
- VIP用户优先显示
- 审核历史记录

**使用方法:**
1. 点击左侧菜单"聚会管理" > "聚会审核"
2. 查看待审核聚会列表（VIP用户的聚会会优先显示）
3. 点击聚会查看详细信息
4. 审核聚会内容是否合规
5. 点击"通过"或"拒绝"按钮
6. 如果拒绝，需要填写拒绝原因
7. 审核完成后，用户会收到通知

**审核标准:**
- 聚会标题和描述是否合规
- 聚会图片是否合适
- 聚会时间和地点是否合理
- 票价设置是否合理
- 参与限制是否合理

**审核时效:**
- 普通用户: 4-12小时内完成审核
- 月付VIP: 2小时内完成审核
- 季付/年付VIP: 15分钟内完成审核

### 4. 订单管理
管理平台所有订单

**功能特性:**
- 订单列表查看
- 订单状态筛选
- 订单详情查看
- 退款处理
- 订单导出

**使用方法:**
1. 点击左侧菜单"订单管理"
2. 使用筛选器按状态、时间、金额、支付方式筛选订单
3. 点击订单查看详情
4. 查看订单完整信息和支付记录
5. 处理退款申请：
   - 查看退款原因
   - 点击"同意退款"或"拒绝退款"
   - 同意后系统自动退款到用户钱包

### 5. 财务管理
管理平台财务数据

**功能特性:**
- 收入统计和趋势图表
- 提现申请审核
- 资金流水查询
- 财务报表导出

**使用方法:**
1. 点击左侧菜单"财务管理"
2. 查看收入统计（票务收入、服务费收入、VIP收入、手续费收入）
3. 查看收入趋势图表
4. 审核提现申请：
   - 查看提现申请列表
   - 点击查看提现详情
   - 验证用户信息和银行卡信息
   - 点击"通过"或"拒绝"
   - 通过后系统自动执行提现
5. 查看资金流水记录
6. 导出财务报表（按时间范围）

### 6. 内容管理
管理平台内容和配置

**功能特性:**
- Banner图片管理
- 公告通知发布
- 帮助文档管理
- 图片上传和压缩

**使用方法:**
1. 点击左侧菜单"内容管理"
2. Banner管理：
   - 点击"添加Banner"上传图片
   - 拖拽调整Banner显示顺序
   - 点击"启用"或"禁用"控制Banner显示
   - 点击"删除"移除Banner
3. 公告管理：
   - 点击"发布公告"
   - 填写公告标题和内容
   - 选择公告类型和发布时间
   - 点击"发布"
4. 帮助文档：
   - 点击"添加文档"
   - 填写文档标题和内容
   - 选择文档分类
   - 点击"保存"

### 7. 数据分析
查看详细的数据分析报表

**功能特性:**
- 用户分析（增长、活跃度、留存率）
- 聚会分析（创建量、参与率、热门分类）
- 收入分析（趋势、来源、手续费）
- 自定义时间范围
- 报表导出（PDF/Excel）

**使用方法:**
1. 点击左侧菜单"数据分析"
2. 选择分析维度（用户/聚会/收入）
3. 选择时间范围（日/周/月/年）
4. 查看分析图表和数据
5. 点击"导出报表"下载数据

### 8. 系统设置
管理系统配置（仅超级管理员）

**功能特性:**
- 管理员账号管理
- 角色权限配置
- 操作日志查看
- 系统参数配置

**使用方法:**
1. 点击左侧菜单"系统设置"
2. 管理员管理：
   - 点击"添加管理员"
   - 填写管理员信息
   - 选择角色
   - 点击"保存"
3. 角色权限：
   - 点击"添加角色"
   - 填写角色名称
   - 勾选权限
   - 点击"保存"
4. 操作日志：
   - 查看所有管理员的操作记录
   - 按时间、操作类型筛选
5. 系统参数：
   - 修改平台基础配置
   - 点击"保存"应用更改

### 9. App版本管理
管理App版本发布

**功能特性:**
- 版本上传
- 更新策略配置
- 下载统计
- 版本状态管理
- 用户反馈处理

**使用方法:**
1. 点击左侧菜单"App管理"
2. 上传新版本：
   - 点击"上传版本"
   - 上传APK/IPA文件
   - 填写版本信息（版本号、更新说明）
   - 选择更新策略（强制更新/推荐更新）
   - 点击"发布"
3. 管理版本：
   - 查看版本列表
   - 点击"上架"或"下架"控制版本状态
   - 查看下载统计
4. 用户反馈：
   - 查看用户反馈列表
   - 点击查看反馈详情
   - 回复用户反馈

## 常见操作

### 搜索和筛选
大部分列表页面都支持搜索和筛选功能：
1. 使用顶部搜索框输入关键词
2. 点击"筛选"按钮打开筛选面板
3. 选择筛选条件
4. 点击"确定"应用筛选
5. 点击"重置"清除筛选条件

### 数据导出
支持导出的页面都有"导出"按钮：
1. 应用筛选条件（可选）
2. 点击"导出"按钮
3. 选择导出格式（Excel/CSV/PDF）
4. 等待导出完成
5. 下载导出文件

### 批量操作
部分页面支持批量操作：
1. 勾选需要操作的项目
2. 点击顶部批量操作按钮
3. 确认操作
4. 等待操作完成

### 主题切换
系统支持亮色/暗色主题：
1. 点击右上角用户头像
2. 点击"主题设置"
3. 选择"亮色"、"暗色"或"跟随系统"
4. 主题立即生效

## 权限说明

### 角色类型

#### 超级管理员
- 拥有所有权限
- 可以管理其他管理员
- 可以配置系统设置
- 可以查看所有数据

#### 运营管理员
- 用户管理（查看）
- 聚会审核
- 订单管理（查看）
- 内容管理
- 数据分析（查看）

#### 财务管理员
- 订单管理（查看）
- 财务管理（全部权限）
- 数据分析（财务相关）

#### 客服管理员
- 用户管理（查看）
- 订单管理（查看）
- 聚会管理（查看）
- 用户反馈处理

### 权限粒度
- **页面权限**: 控制菜单显示和页面访问
- **操作权限**: 控制具体的增删改查操作
- **数据权限**: 控制可访问的数据范围
- **功能权限**: 控制特定功能的使用

## 常见问题

### Q: 忘记密码怎么办？
A: 请联系超级管理员重置密码。超级管理员可以在"系统设置" > "管理员管理"中重置任何管理员的密码。

### Q: 为什么看不到某些菜单？
A: 这是由于权限限制。不同角色的管理员只能看到和访问自己权限范围内的功能。如需更多权限，请联系超级管理员。

### Q: 如何提高审核效率？
A: 
1. 使用筛选功能优先处理VIP用户的聚会
2. 使用快捷键快速操作
3. 批量审核相似的聚会
4. 设置审核模板快速填写审核意见

### Q: 数据统计不准确怎么办？
A: 
1. 检查筛选条件是否正确
2. 刷新页面重新加载数据
3. 清除浏览器缓存
4. 如果问题持续，请联系技术支持

### Q: 如何导出大量数据？
A: 
1. 使用筛选功能缩小数据范围
2. 分批导出数据
3. 选择合适的导出格式（Excel适合小数据量，CSV适合大数据量）
4. 避免在高峰期导出大量数据

### Q: 系统响应慢怎么办？
A: 
1. 检查网络连接
2. 清除浏览器缓存
3. 关闭不必要的浏览器标签页
4. 使用Chrome或Edge浏览器以获得最佳性能
5. 如果问题持续，请联系技术支持

### Q: 如何保证数据安全？
A: 
1. 定期修改密码
2. 不要与他人共享账号
3. 退出时点击"登出"按钮
4. 不要在公共电脑上保存密码
5. 发现异常操作立即联系超级管理员
