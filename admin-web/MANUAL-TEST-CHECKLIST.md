## ❌ 十二、常见错误检查清单

### 12.1 数据格式错误
检查以下错误是否出现：
- [ ] NaN - 应该显示为 '-' 或 '0'
- [ ] undefined - 应该显示为 '-'
- [ ] null - 应该显示为 '-'
- [ ] Invalid Date - 应该显示为 '-'
- [ ] [object Object] - 应该解析为具体值
- [ ] 空白或空字符串 - 应该显示为 '-'

### 12.2 页面显示错误
- [ ] 404 页面 - 应该重定向到登录或显示404页面
- [ ] 500 错误页面 - 不应该出现
- [ ] 空白页面 - 不应该出现
- [ ] 加载中一直转圈 - 不应该超过5秒
- [ ] 图片加载失败 - 应该显示默认图

### 12.3 交互错误
- [ ] 按钮点击无反应
- [ ] 表单提交无响应
- [ ] 弹窗无法关闭
- [ ] 分页切换无效
- [ ] 筛选条件不生效
